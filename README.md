# Web Technology Practicals

This repository contains basic web technology and JavaScript practice files created for learning and experimentation. It includes HTML, JavaScript, and browser object demos covering core front-end concepts.

## Project Overview

The project is organized into practical exercises that help understand:

- HTML and JavaScript basics
- JavaScript functions and scope
- Window and document methods
- Callbacks and asynchronous programming
- Generators and higher-order functions
- Event handling and browser interactions

## Repository Structure

- `All/` - Collection of JavaScript and browser-related examples
- `Prac1/` - Practice exercises for CSS, JavaScript, and resume-related HTML files
- `Prac2/` - Function and JavaScript practice programs

## Examples Included

- Window methods
- Function declarations and expressions
- Arrow functions
- Parameterized functions
- Default parameters
- IIFE (Immediately Invoked Function Expression)
- Callback functions
- Async operations
- Generators
- Hosting and hoisting concepts

## How to Run

1. Open the repository in a browser or code editor.
2. Navigate to any `.html` file.
3. Open it in a browser to see the JavaScript output.

Example:

- `All/window.method2.html`
- `Prac2/function1.html`
